# Agro Forte, Futuro Sustentável: Equilíbrio entre Produção e Meio Ambiente

## 📝 Objetivo do Projeto
Este site foi desenvolvido para o Concurso Agrinho 2026. O objetivo principal é conscientizar produtores e a comunidade sobre o equilíbrio entre a alta produtividade agrícola e a preservação ambiental. O site apresenta os pilares tecnológicos de conservação, além de fornecer uma ferramenta interativa de autodiagnóstico para propriedades rurais.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica e recursos de acessibilidade (WAI-ARIA).
- **CSS3:** Estilização responsiva (Media Queries) e gerenciamento de layouts modernos.
- **JavaScript (Vanilla JS):** Manipulação de elementos do DOM, cálculos matemáticos lógicos e controle de acessibilidade textual.

## 👥 Recursos de Acessibilidade Implementados
- **Navegação por Teclado:** Suporte completo via tecla `TAB` com indicadores visuais de foco.
- **Leitores de Tela:** Uso de atributos semânticos `aria-live` e `aria-label`.
- **Controle de Interface:** Botões para aumento/diminuição de fonte e modo de alto contraste para baixa visão e daltonismo.
